YouTube Script Extractor

Paste a YouTube URL and pull its captions as plain text or an SRT subtitle file. Runs locally on your own machine.

Download for Windows Source

Windows 64-bit · 26 MB · No Python required

How to use

  1. Run the downloaded exe. Your browser opens on its own.
  2. Paste a YouTube URL. A thumbnail means it was recognised.
  3. Pick a format and hit Extract, then copy the result or save it as .srt / .txt.

What it does

Captions

Both manual and auto-generated tracks. Prefers Korean and English.

Three formats

SRT subtitles, plain text, or text with timestamps.

Stays local

The server runs on your own machine. Nothing is sent anywhere else.

Easy to work with

Line numbers, one-click copy, file download, light and dark themes.
