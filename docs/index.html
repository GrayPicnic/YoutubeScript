YouTube Script Extractor

유튜브 영상 URL만 넣으면 자막을 가져와 일반 텍스트 또는 SRT 자막 파일로 뽑아주는 도구입니다. 설치 없이 exe 하나로 실행되고, 모든 처리는 내 PC에서 로컬로 이뤄집니다.

Windows용 다운로드 소스 코드

Windows 64비트 · 약 26MB · Python 설치 불필요

사용 방법

  1. 다운로드한 exe를 실행합니다. 잠시 뒤 브라우저가 자동으로 열립니다.
  2. 유튜브 URL을 붙여넣습니다. 썸네일이 뜨면 인식된 것입니다.
  3. 형식을 고르고 Extract를 누릅니다. 결과를 복사하거나 .srt / .txt 파일로 저장할 수 있습니다.

기능

자막 추출

수동 자막과 자동 생성 자막을 모두 지원합니다. 한국어·영어를 우선 찾고, 없으면 사용 가능한 자막을 씁니다.

출력 형식 3종

SRT 자막 파일, 타임스탬프 없는 일반 텍스트, 타임스탬프 포함 텍스트 중에 고를 수 있습니다.

로컬 처리

서버가 내 PC 안에서만 돕니다. 영상 주소나 자막이 외부로 전송되지 않습니다.

편집 편의

줄 번호 표시, 스크롤 동기화, 결과 복사, 파일 다운로드, 라이트·다크 테마를 지원합니다.

왜 웹에서 바로 안 되나요

이 페이지에서 바로 자막을 뽑을 수 있으면 좋겠지만, 유튜브가 브라우저의 직접 자막 요청을 차단합니다. 자막 트랙 주소를 알아내는 것까지는 되는데 마지막 요청이 빈 응답을 돌려줍니다.

서버 쪽에서 요청할 때만 정상 동작하기 때문에 백엔드가 반드시 필요하고, GitHub Pages는 정적 파일만 서빙하므로 여기서 실행할 수 없습니다. 그래서 내 PC에서 도는 exe 형태로 배포합니다.

소스로 실행하기

Python 3.10 이상이 필요합니다.

git clone https://github.com/graypicnic/YoutubeScript.git
cd YoutubeScript
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py

실행하면 http://127.0.0.1:8787 이 자동으로 열립니다. Windows에서는 run.bat 더블클릭으로도 실행됩니다.

제약

자막이 없는 영상은 지원하지 않습니다. 음성 인식 기능은 로컬 CPU 환경에서 고유명사 오인식이 심하고 속도도 느려서 제외했습니다.

개인용 로컬 도구입니다. 포트 8787을 사용하므로, 이미 다른 프로그램이 쓰고 있으면 실행되지 않습니다.
